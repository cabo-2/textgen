# Manual test workspace

- Store manual test prompts, sample assets, and per-run notes under this `tests/` tree.
- See `docs/manual-integration-test-harness.md` for the full checklist and command examples.
- Put transient artifacts (run outputs, downloaded responses, screenshots) under `tests/runs/` so they stay git-ignored.
- Drop any ad-hoc images you use for vision runs under `tests/assets/images/` (also git-ignored).
